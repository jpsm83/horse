**Job:** Locales, routing, message files, cookie sync.  
**Upstream:** [`../product/go-to-market.md`](../product/go-to-market.md)  
**Status:** **drift**  
**Code roots:** `i18n/`, `messages/en.json`, `messages/es.json`, `proxy.ts`

Coding rules: [`../conventions/i18n.md`](../conventions/i18n.md). Preferences Save: [`profile.md`](profile.md).

---

## Shipped

| Setting | Value |
|---------|--------|
| Locales | `en`, `es` |
| Default | `en` (unprefixed `/`) |
| Spanish | `/es/…` (`localePrefix: 'as-needed'`) |
| Path slugs | English (`/es/signin`) |

Priority: URL `[locale]` → `NEXT_LOCALE` cookie → `Accept-Language` → `en`. Account users always have `personalDetails.preferredLanguage`. Cookie synced on register, login, Google bridge, preferences Save. **No** header language switcher — preferences tab only. Root `app/not-found.tsx` redirects to `/` (no intl provider at that layer).

Emails: `buildLocalizedAppLink` (`i18n/appLinks.ts`).

Tests: `tests/i18n/resolveLocale.test.ts`, `tests/i18n/messages.test.ts` (en/es key parity).
