# Chat — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 1:1 chat with REST, blocks, DM policy, `/messages` module, desktop popover, Planning reply entry, Socket.io last.

**Architecture:** New models `ChatThread`, `ChatMessage`; `chatService`; REST under `/api/v1/chat`; UI provider for popover; optional custom `server.ts` for Socket.io.

**Tech Stack:** Mongoose, Zod, Vitest, TanStack Query, Socket.io (final task).

## Global Constraints

- Spec: [`../specs/2026-08-18-chat-design.md`](../specs/2026-08-18-chat-design.md)
- Text-only messages; context as `contextPrefix` string
- 1:1 only; chat stays up under stable write-lock
- Work from `equus/`; colocated tests
