# Web UI i18n — how to write strings and navigation

**Job:** How to add copy and locale-aware links. Not which locales are shipped.  
**Also open (only if needed):** adding a locale or changing cookie/URL prefix → [`../engineering/i18n.md`](../engineering/i18n.md). Preferences language Save → [`../engineering/profile.md`](../engineering/profile.md).

- **Strings** — put user-facing copy in `messages/*.json`. Use `useTranslations` / `getTranslations`. No hardcoded UI copy in components. Add every new key to **all** files under `messages/`.
- **Navigation** — in-app routes under `app/[locale]/` use `Link`, `useRouter`, and `redirect` from `@/i18n/navigation` (locale-aware). Do **not** use `next/link` or raw `<a href="/…">` for in-app paths. Use [`ExternalLink`](../../components/navigation/external-link.tsx) for `mailto:`, `tel:`, and external `https:` URLs only. Use [`AppHomeLink`](../../components/navigation/app-home-link.tsx) for “home” footers (`/` guest vs `/home` signed-in).
- **Do not** add a header language switcher. Language is changed on the user preferences tab.
- **API** — keep route handlers locale-agnostic; clients translate `error.code`.
