# MongoDB models

Conventions, naming, and domain rules for Mongoose models:

* **File naming:** own-collection models are PascalCase singular matching the model (`User.ts`, `Horse.ts`); reusable embed schemas are camelCase under `models/sharedSchemas/`; parent-only embeds are inline.
* **No hard deletes** — deactivate via `lib/lifecycle/deactivateDocument.ts` + `deactivationAuditFields`; anonymize inactive user PII via `lib/lifecycle/anonymizeUserPii.ts`. Details: [equus/docs/engineering/dataLifecycle.md](../engineering/dataLifecycle.md), [equus/docs/engineering/piiAnonymization.md](../engineering/piiAnonymization.md).
* **Ownership transfers** use `OwnershipTransfer` (consent before apply); collaborations link via `WorkplaceRelationship`. Details: [equus/docs/engineering/ownershipTransfer.md](../engineering/ownershipTransfer.md), [equus/docs/engineering/relationships.md](../engineering/relationships.md).
